Gesture Control

Hand signs, face & head moves, eye gaze, desk taps and whistles → Chrome. Everything runs on this device.

Get started


  1. Chrome asks once for this extension. The microphone is only used if you switch on Sounds.
  2. The badge on the toolbar icon shows ON, or II while paused. Alt+Shift+G pauses and resumes from anywhere.
  3. Pick a preset below, then calibrate (right): about a minute, and it makes everything far more reliable.

Gestures → actions

A hand sign must be held still for a moment and fires once; drop your hand to do it again. Face and head moves fire once per move. Single desk taps wait ~0.6 s to rule out a double tap.

Anki desktop (optional)

For the "Anki:" actions: install the AnkiConnect add-on in Anki desktop (Tools → Add-ons → Get Add-ons, code 2055492159), keep Anki open, then connect. Anki asks once to allow this extension.

Privacy & limits

Video and sound are analysed on this device and never recorded or sent anywhere. The only network request is to Anki on 127.0.0.1, if you use the Anki actions.

Your camera light (and Chrome's mic indicator) stay on while Gesture Control is on. Turn it off from the toolbar popup.

It only acts while a Chrome window is in front, so gestures made while you use other apps are ignored. It can't act on chrome:// pages, the Chrome Web Store or the built-in PDF viewer (tab actions still work there). Key actions send synthetic key presses: apps that listen for keys (slides, AnkiWeb, games) react, but the browser's own built-in key shortcuts don't run.
